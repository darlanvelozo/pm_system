# Decisões para homologação

- Confirmar política de consulta dos operadores: implementado acesso apenas aos próprios registros.
- Confirmar se número manual é único globalmente ou por ano/unidade. Implementada unicidade global.
- Validar visualmente os PDFs sintéticos contra modelos oficiais, sobretudo textos longos e posicionamento dos emblemas.
- Confirmar qualidade do emblema institucional de baixa resolução extraído isoladamente do modelo (sem dados pessoais).
- Definir retenção dos boletins, rascunhos, auditoria, backups e procedimento de correção após emissão.
- Configurar PostgreSQL, SMTP, domínio Vercel/Render e primeiro administrador antes de produção.
